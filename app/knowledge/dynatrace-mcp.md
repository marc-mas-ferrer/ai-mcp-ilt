## Dynatrace MCP server

The Dynatrace MCP server implements the Model Context Protocol, which lets an AI assistant work with external tools and data. It allows assistants such as GitHub Copilot to query Dynatrace data, generate DQL, investigate problems and analyse telemetry directly from the IDE, limited by the permissions on the platform token it was given. The MCP platform token is a different credential from the Api-Token used for OTLP ingestion.
